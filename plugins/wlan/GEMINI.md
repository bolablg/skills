# Wlan Studio

For Wlan styles, drafts, or rewrites, load the bundled `skills/wlan/SKILL.md`
and its `references/tool-contract.md`. Use the connected remote Wlan MCP tools.
Let the host handle OAuth; the user signs in and explicitly approves a workspace
in the browser. Never use a local Wlan daemon, pairing flow, or API key. Start
work from the connected chat; this extension does not wake an idle assistant.
